How I built this portfolio

01

Content and copy

Started with writing all the case studies content and worked with Claude to structure, refine, and edit the copy - making sure each section communicates clearly and concisely.

02

Design outline in Figma

In Figma by creating a design outline and defining visual tokens - colour, typography, and spacing - to establish a clear foundation before moving on to code.

03

Development with Claude Code

Used Claude Code to develop the full website - translating the Figma design into working HTML and CSS, and iterating on layout and interactions.

04

Published via GitHub pages

Pushed development files to GitHub and published via GitHub pages to keep it live, version-controlled, and easy to update.
